# AutoCare Hub — logo directions for review

The current mark is a temporary blue square with an `A`. These are lightweight, code-native directions for a later identity decision; none is final until approved.

## Option A — service orbit (recommended)

Circular mark with a central hub and two orbital arcs. It reads as a wheel, network, and trusted marketplace at small sizes. Keep the wordmark in the existing high-contrast navy/blue treatment.

## Option B — road glyph

Two parallel rounded strokes create a road that turns into an `A`. It is more distinctive in a favicon and works well as a single-color stamp for provider verification.

## Option C — shielded wheel

A simplified wheel inside a soft shield. It puts trust and quality ahead of marketplace/network meaning and is strongest for the provider/admin product.

### Evaluation criteria

Choose the final mark using recognition at 16px, monochrome reproduction, app-icon cropping, accessibility contrast, and whether the mark still makes sense outside automotive repair. Implement the winner only in `src/shared/ui/brand-logo/BrandLogo.tsx` and keep the wordmark text separate.
