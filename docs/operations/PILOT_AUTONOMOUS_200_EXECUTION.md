# AutoCare Hub — единый 200-пунктовый аудит

Единый аудит состоит из двух сохранённых очередей по 100 пунктов:

1. [Пункты 1–100: автономное выполнение](./PILOT_AUTONOMOUS_100_EXECUTION.md).
2. [Пункты 101–200: следующие автономные шаги](./PILOT_AUTONOMOUS_100_NEXT.md).

Вторая очередь перенумеровывается проверяющим контрактом с `1–100` в `101–200`,
поэтому исходные документы остаются читаемыми и не дублируют 200 описаний.
Команда `npm run check:pilot-autonomous-200` проверяет обе половины, отсутствие
пропусков/дубликатов и рассчитывает общую готовность.

Текущий доказанный статус: **200 пунктов, 193 выполнено, 7 частичных,
готовность 96,5%**. Частичные пункты требуют реального staging/production,
multi-process инфраструктуры, pilot evidence или deployed SEO/Lighthouse;
локальные фикстуры намеренно не засчитываются вместо них.
